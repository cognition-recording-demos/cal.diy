# Pirsch Analytics

Privacy-friendly, cookieless analytics for your booking pages.

## Setup

1. Create a website dashboard at [pirsch.io](https://pirsch.io) and copy its identification code (found under Settings → Developer → Identification Code).
2. Install the Pirsch Analytics app from the Cal app store.
3. Enable the app on an event type and paste the identification code.

The app injects the Pirsch tracking snippet (`https://api.pirsch.io/pa.js`) on the event type's booking pages. Pirsch is cookieless, so no cookie banner is required.
