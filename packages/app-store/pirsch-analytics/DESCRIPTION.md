Pirsch is a privacy-friendly, cookieless web analytics tool. It is GDPR, CCPA, and Schrems II compliant by design and doesn't require a cookie banner.

Use the Pirsch Analytics app to track visits and conversions on your booking pages. Add your Pirsch identification code to an event type and the lightweight tracking script is injected on its booking pages automatically.
