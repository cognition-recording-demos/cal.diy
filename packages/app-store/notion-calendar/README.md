# Notion Calendar

Notion Calendar is a link-as-an-app integration that points users to [notion.com/product/calendar](https://www.notion.com/product/calendar). It does not use OAuth or the Cal.diy API — installing it simply surfaces a link to Notion Calendar from the Cal.diy app store.

## Installation

1. Go to `<baseUrl>/apps` in your Cal.diy instance.
2. Find **Notion Calendar** and click **Install**.
3. Once installed, open the app to be redirected to https://www.notion.com/product/calendar to download and set up Notion Calendar.
